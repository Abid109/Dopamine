Install

  1. Download Dopamine.apk and open it.
  2. If Android asks, allow Install unknown apps for your browser or file manager.
  3. Google Play Protect may warn about an app from outside the Play Store. Choose Install anyway.
  4. Later updates install over the old app from Settings, App updates, or through Obtainium. Your data is kept.

iPhone, desktop and any browser

The web app works offline once opened and can be installed like an app.

Open the web app
  • iPhone: open it in Safari, tap Share, then Add to Home Screen.
  • Chrome or Edge: use the install icon in the address bar.

Limits of the web version: alerts only fire while the app is open, there is no background GPS, and browsers can clear stored data, so export a backup now and then.
