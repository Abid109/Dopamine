# Exercise Library

Dopamine includes 18 calisthenics movements. Each has a difficulty, default sets, reps and minutes, an intensity (MET) value and a progression path.

| Category | Movements |
| --- | --- |
| **Push** | Push-ups, Diamond Push-ups, Parallel Bar Dips, Pike Push-ups, Handstand Push-ups |
| **Pull** | Pull-ups, Chin-ups, Inverted Rows (Australian), Bar Muscle-ups |
| **Legs** | Bodyweight Squats, Walking Lunges, Pistol Squats, Calf Raises |
| **Core** | Forearm Plank, Hollow Body Hold, Hanging Leg Raises |
| **Full Body** | Burpees, Mountain Climbers |

Difficulty levels are Beginner, Intermediate and Advanced.

The Forearm Plank and Hollow Body Hold are timed holds: you enter seconds instead of repetitions. See [Calorie Calculation](Calorie-Calculation) for the intensity and tempo of every movement.

Missing a movement? Use **Custom Exercise** in [Logging Workouts](Logging-Workouts), or [suggest it](https://github.com/Abid109/Dopamine/issues/new/choose).
