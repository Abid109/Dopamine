# PDF Reports and Backup

Both live in **Settings** under Local Data & Export.

## PDF fitness report

1. Tap **Preview & Print Report** to see it on screen, or **Download Fitness Report (PDF)** to create it directly.
2. On Android the PDF opens in your phone's PDF viewer. If you have no viewer, the share sheet opens so you can save or send it.

The first time you create a PDF the app needs internet to load the PDF library.

## JSON backup

- **Export JSON** saves all your data into one file through the share sheet. Keep it in a safe place such as Drive.
- **Import Backup** restores a backup file and **replaces** the data currently in the app.

To merge only parts of another file instead, use [Share and Receive](Share-and-Receive).

## Reset

**Reset All Data** erases everything saved in the app after you confirm. Export a backup first if you might want your data back.
